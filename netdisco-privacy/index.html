Privacy Policy

Last updated: February 3, 2025

Introduction

NetDisco is a network diagnostic application for macOS developed by SmartColibri. This privacy policy explains how the application handles your data.

No personal data is collected, stored, or shared by SmartColibri.

All data stays on your device.

Data stored locally

NetDisco stores the following data on your device only (in the application's sandbox container):

  • Speed test history: test results (speed, latency, date, approximate location)
  • Network quality history: latency, jitter and packet loss measurements over 24 hours
  • Network profiles: Wi-Fi network names and the related performance statistics
  • Favorites: saved DNS, WHOIS and Traceroute query targets
  • Preferences: application settings (appearance, notifications, etc.)

External services

The application communicates with the following services in order to work:

ServiceData sentPurpose
speed.cloudflare.comHTTP requestsSpeed measurement (download/upload)
one.one.one.oneHTTP HEAD requestsLatency measurement
ipify.orgHTTP requestDetection of your public IP address
ipapi.coIP addressApproximate geolocation
ipwho.isRouter IP addressesGeolocation of hops (traceroute)
WHOIS servers (port 43)Domain names or IP addressesRegistry lookups
Public DNS serversDomain namesDNS resolution

None of this data is collected, stored, or processed by SmartColibri.

Location

If you grant location access, NetDisco uses your geographic position only to:

  • Display your location in speed test results
  • Improve the accuracy of network diagnostics

This information is stored locally with the test history and is never transmitted to SmartColibri.

Data not collected

NetDisco does not collect:

  • Personally identifiable information
  • Browsing data
  • Contact information
  • Financial data
  • Health data
  • Biometric data
  • Advertising identifiers

Analytics and advertising

✅ No analytics SDK (no Google Analytics, Firebase, etc.)

✅ No advertisements

✅ No data sharing with third parties for commercial purposes

Security

  • All network communications use HTTPS (except WHOIS, which uses the standard protocol on port 43)
  • Data is stored in the application's sandbox container, protected by macOS
  • No data is transmitted to SmartColibri servers

Your rights

You can at any time:

  • Delete the history of speed tests from within the application
  • Delete the application to erase all local data
  • Revoke location access in System Settings → Privacy

Contact

For any question about this privacy policy:

SmartColibri
Email: privacy@smartcolibri.com

This policy is published in French, English and Traditional Chinese. In case of any discrepancy, the French version prevails.

Introduction

NetDisco est une application macOS développée par SmartColibri. Cette politique de confidentialité explique comment l'application traite vos données.

Aucune donnée personnelle n'est collectée, stockée ou partagée par SmartColibri.

Toutes les données restent sur votre appareil.

Données stockées localement

NetDisco stocke les données suivantes uniquement sur votre appareil (dans le conteneur sandbox de l'application) :

✅ Aucune publicité

✅ Aucun partage de données avec des tiers à des fins commerciales

Sécurité

  • Toutes les communications réseau utilisent HTTPS (sauf WHOIS qui utilise le protocole standard sur port 43)
  • Les données sont stockées dans le conteneur sandbox de l'application, protégé par macOS
  • Aucune donnée n'est transmise à des serveurs SmartColibri

Vos droits

Vous pouvez à tout moment :

  • Supprimer l'historique des tests de débit depuis l'application

隱私權政策

最後更新：2025 年 2 月 3 日

簡介

NetDisco 是由 SmartColibri 開發的 macOS 應用程式。本隱私權政策說明應用程式如何處理您的資料。

SmartColibri 不會收集、儲存或分享任何個人資料。

所有資料都保留在您的裝置上。

儲存在本機的資料

NetDisco 會將下列資料僅儲存在您的裝置上（位於應用程式的沙盒容器內）：

  • 速度測試記錄：測試結果（速度、延遲、日期、大致位置）
  • 網路品質記錄：24 小時內的延遲、抖動與封包遺失量測值
  • 網路設定檔：Wi-Fi 網路名稱及相關效能統計
  • 我的最愛：已儲存的 DNS、WHOIS 與 Traceroute 查詢目標
  • 偏好設定：應用程式設定（外觀、通知等）

外部服務

為了正常運作，應用程式會與下列服務通訊：

服務傳送的資料用途
speed.cloudflare.comHTTP 請求速度量測（下載／上傳）
one.one.one.oneHTTP HEAD 請求延遲量測
ipify.orgHTTP 請求偵測您的公開 IP 位址
ipapi.coIP 位址大致地理定位
ipwho.is路由器 IP 位址各躍點的地理定位（traceroute）
WHOIS 伺服器（連接埠 43）網域名稱或 IP 位址查詢註冊資料
公用 DNS 伺服器網域名稱DNS 解析

SmartColibri 不會收集、儲存或處理上述任何資料。

位置

若您允許存取位置，NetDisco 僅會將您的地理位置用於：

  • 在速度測試時顯示您的所在位置
  • 提升網路診斷的準確度

此資訊會與測試記錄一同儲存在本機，絕不會傳送給 SmartColibri。

不收集的資料

NetDisco 不會收集：

  • 個人身分識別資料
  • 瀏覽資料
  • 聯絡資訊
  • 財務資料
  • 健康資料
  • 生物辨識資料
  • 廣告識別碼

分析與廣告

✅ 無分析 SDK（不使用 Google Analytics、Firebase 等）

✅ 無廣告

✅ 不會為商業目的與第三方分享資料

安全性

  • 所有網路通訊皆使用 HTTPS（WHOIS 除外，其使用連接埠 43 上的標準協定）
  • 資料儲存在應用程式的沙盒容器內，並受 macOS 保護
  • 不會有任何資料傳送到 SmartColibri 的伺服器

您的權利

您可隨時：

  • 從應用程式內刪除速度測試記錄
  • 刪除應用程式以清除所有本機資料
  • 在「系統設定」 → 「隱私權與安全性」中撤銷位置存取權限
