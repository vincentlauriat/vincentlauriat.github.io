❓ Frequently Asked Questions

How do I run a speed test?

Click the NetDisco icon in the menu bar → select "Speed Test" (or use the shortcut Cmd+Shift+S).

Is my data sent to any servers?

No, all your data is stored locally on your Mac. NetDisco does not collect any personal information. See our Privacy Policy for more details.

How do I delete the test history?

Open Settings (Cmd+,) → "General" tab → click "Clear History".

How do I switch between menu bar mode and application mode?

Open Settings → "General" tab → "Display Mode" section → choose "Application" to get a main window, or "Menu Bar" for a discreet mode.

What is "Geek Mode"?

Geek Mode hides the advanced tools (MTR, Multi-ping, SSL Inspector, etc.) to simplify the interface. You can turn it on/off in Settings → "Geek Mode" or by Option+clicking the menu bar icon.

How do I enable scheduled quality tests?

Settings → "Advanced" tab → "Scheduled Tests" section → check "Enable" and choose the interval (5, 15, 30 or 60 minutes).

Is NetDisco compatible with macOS Sequoia?

Yes, NetDisco is compatible with macOS 13.0 (Ventura) and later, including Sonoma and Sequoia.

Does the app require an Internet connection?

Yes, NetDisco needs an active Internet connection to run network tests. The app automatically monitors the state of your connection.

How do I use Siri Shortcuts?

NetDisco includes 8 Siri Shortcuts (speed test, network quality, remote-work diagnostic, etc.). Open the Shortcuts app on your Mac to set them up.

How do I sync my data between Macs?

Settings → "Advanced" tab → turn on "iCloud Sync". Your favorites, profiles and history will be synced automatically (requires iCloud to be enabled).

❓ Foire Aux Questions

Comment lancer un test de débit ?

Cliquez sur l'icône NetDisco dans la barre de menus → sélectionnez "Test de débit" (ou utilisez le raccourci Cmd+Shift+S).

Les données sont-elles envoyées à des serveurs ?

Non, toutes vos données sont stockées localement sur votre Mac. NetDisco ne collecte aucune information personnelle. Consultez notre Politique de confidentialité pour plus de détails.

Comment supprimer l'historique des tests ?

Ouvrez les Réglages (Cmd+,) → onglet "Général" → cliquez sur "Effacer l'historique".

Comment passer du mode barre de menus au mode application ?

Ouvrez les Réglages → onglet "Général" → section "Mode d'affichage" → choisissez "Application" pour avoir une fenêtre d'accueil, ou "Barre de menus" pour un mode discret.

Qu'est-ce que le "Mode Geek" ?

Le Mode Geek masque les outils avancés (MTR, Multi-ping, SSL Inspector, etc.) pour simplifier l'interface. Vous pouvez l'activer/désactiver dans Réglages → "Mode Geek" ou en faisant Option+Clic sur l'icône de la barre de menus.

Comment activer les tests qualité planifiés ?

Réglages → onglet "Avancé" → section "Tests planifiés" → cochez "Activer" et choisissez l'intervalle (5, 15, 30 ou 60 minutes).

NetDisco est-il compatible avec macOS Sequoia ?

Oui, NetDisco est compatible avec macOS 13.0 (Ventura) et supérieur, incluant Sonoma et Sequoia.

L'app nécessite-t-elle une connexion Internet ?

Oui, NetDisco a besoin d'une connexion Internet active pour effectuer les tests réseau. L'app surveille automatiquement l'état de votre connexion.

Comment utiliser les raccourcis Siri ?

NetDisco intègre 8 raccourcis Siri (test de débit, qualité réseau, diagnostic télétravail, etc.). Ouvrez l'app Raccourcis sur votre Mac pour les configurer.

Comment synchroniser mes données entre Macs ?

Réglages → onglet "Avancé" → activez "Synchronisation iCloud". Vos favoris, profils et historique seront synchronisés automatiquement (nécessite iCloud activé).

❓ 常見問題

如何執行速度測試？

點選選單列中的 NetDisco 圖示 → 選擇「速度測試」（或使用快速鍵 Cmd+Shift+S）。

我的資料會傳送到伺服器嗎？

不會，您的所有資料都儲存在您 Mac 的本機。NetDisco 不會收集任何個人資訊。詳情請參閱我們的隱私權政策。

如何刪除測試記錄？

開啟「設定」（Cmd+,） → 「一般」分頁 → 點選「清除記錄」。

如何在選單列模式與應用程式模式之間切換？

開啟「設定」 → 「一般」分頁 → 「顯示模式」區段 → 選擇「應用程式」以顯示主視窗，或選擇「選單列」使用低調模式。

什麼是「極客模式」？

極客模式會隱藏進階工具（MTR、Multi-ping、SSL Inspector 等）以簡化介面。您可在「設定」 → 「極客模式」中開啟或關閉，或按住 Option 鍵點選選單列圖示。

如何啟用排程品質測試？

「設定」 → 「進階」分頁 → 「排程測試」區段 → 勾選「啟用」並選擇間隔（5、15、30 或 60 分鐘）。

NetDisco 與 macOS Sequoia 相容嗎？

相容，NetDisco 支援 macOS 13.0（Ventura）及更新版本，包括 Sonoma 與 Sequoia。

應用程式需要網際網路連線嗎？

需要，NetDisco 需要有效的網際網路連線才能執行網路測試。應用程式會自動監控您的連線狀態。

如何使用 Siri 捷徑？

NetDisco 內建 8 個 Siri 捷徑（速度測試、網路品質、遠距工作診斷等）。請在 Mac 上開啟「捷徑」App 進行設定。

如何在多部 Mac 之間同步我的資料？

「設定」 → 「進階」分頁 → 開啟「iCloud 同步」。您的我的最愛、設定檔與記錄會自動同步（需啟用 iCloud）。
