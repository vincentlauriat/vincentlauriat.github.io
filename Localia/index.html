39Localia

Local AI models for Claude Code, from the macOS menu barDes modèles d'IA locaux pour Claude Code, depuis la barre de menus macOS從 macOS 選單列，為 Claude Code 執行本機 AI 模型

Airplane mode for AI: one switch, and Claude Code runs on your Mac.Le mode avion de l'IA : un interrupteur, et Claude Code tourne sur votre Mac.AI 的飛航模式：一個開關，Claude Code 就在你的 Mac 上執行。

Running models locally is fiddly: pick one that fits your RAM, install an engine, download gigabytes, wire Claude Code to a local server. Pick wrong and it crawls, or the Mac swaps. Localia does each step for you, measures what your Mac can really hold, and keeps every prompt and every line of code on the machine.Faire tourner des modèles en local est laborieux : en choisir un qui tient dans la RAM, installer un moteur, télécharger des gigaoctets, brancher Claude Code sur un serveur local. Un mauvais choix et tout rame, ou le Mac swappe. Localia fait chaque étape pour vous, mesure ce que votre Mac peut vraiment tenir, et garde chaque prompt et chaque ligne de code sur la machine.在本機執行模型很麻煩：要挑一個放得進記憶體的模型、安裝引擎、下載數 GB 檔案，再把 Claude Code 接到本機伺服器。選錯了就會很慢，或讓 Mac 開始使用置換空間。Localia 替你完成每一步，實際量測你的 Mac 能承載多少，並讓每個提示與每一行程式碼都留在這台機器上。

Four jobs, one menu-bar iconQuatre tâches, une icône dans la barre de menus四項工作，一個選單列圖示

Choose a model that fits, install the engine, manage what is downloaded, and launch Claude Code on it. Free, open source, MIT.Choisir un modèle qui tient, installer le moteur, gérer ce qui est téléchargé, et lancer Claude Code dessus. Gratuit, open source, MIT.挑選放得下的模型、安裝引擎、管理已下載的內容，並在其上啟動 Claude Code。免費、開源、MIT 授權。

  • Recommends models that fit this MacRecommande des modèles qui tiennent sur ce Mac推薦適合這台 Mac 的模型

    Scored by llmfit, then corrected with this Mac's real GPU memory limit and re-measured on first load. Speed comes first.Notés par llmfit, puis corrigés avec la vraie limite de mémoire GPU de ce Mac et remesurés au premier chargement. La vitesse d'abord.先由 llmfit 評分，再以這台 Mac 實際的 GPU 記憶體上限修正，並在首次載入時重新量測。速度優先。

  • Installs engines in one clickInstalle les moteurs en un clic一鍵安裝引擎

    Ollama (the official release) and llama.cpp (the official ggml-org macOS arm64 build), with no Homebrew. Every download is SHA-256 verified, atomic and cancellable.Ollama (la version officielle) et llama.cpp (le build officiel ggml-org macOS arm64), sans Homebrew. Chaque téléchargement est vérifié en SHA-256, atomique et annulable.Ollama（官方版本）與 llama.cpp（ggml-org 官方 macOS arm64 版本），無需 Homebrew。每次下載都經 SHA-256 驗證、以原子方式寫入，且可取消。

  • Manages modelsGère les modèles管理模型

    Download with progress, delete, see what is loaded, free the memory. A guard warns before loading when free RAM is short, or when Teams, Outlook or Chrome are eating it.Téléchargement avec progression, suppression, ce qui est chargé, libération de la mémoire. Un garde-fou prévient avant le chargement si la RAM libre manque, ou si Teams, Outlook ou Chrome la dévorent.下載時顯示進度、刪除、查看已載入的模型、釋放記憶體。可用記憶體不足，或 Teams、Outlook、Chrome 佔用太多時，載入前會先提醒。

  • Launches Claude Code where you workLance Claude Code là où vous travaillez在你的工作資料夾啟動 Claude Code

    In a folder you choose, in Terminal, iTerm2 or Ghostty, on Anthropic's cloud or on a local model. Local runs need no Anthropic account.Dans le dossier de votre choix, dans Terminal, iTerm2 ou Ghostty, sur le cloud d'Anthropic ou sur un modèle local. En local, aucun compte Anthropic n'est nécessaire.在你選定的資料夾中，透過 Terminal、iTerm2 或 Ghostty，於 Anthropic 雲端或本機模型上執行。本機執行不需要 Anthropic 帳號。

How a model is pickedComment un modèle est choisi如何挑選模型

Five stages, from the chip to a short list. The fourth one feeds back into the third.Cinq étapes, de la puce à une courte liste. La quatrième nourrit la troisième.從晶片到一份簡短清單，共五個階段。第四階段會回饋給第三階段。

  • Why not trust the score as isPourquoi ne pas croire le score tel quel為何不直接採用評分

    llmfit reasons about total RAM and the quantisation it prefers. The GPU, though, may only use Metal's recommendedMaxWorkingSetSize, and Localia downloads Q4_K_M. Size and speed are recomputed for both.llmfit raisonne sur la RAM totale et la quantification qu'il préfère. Or le GPU ne peut utiliser que le recommendedMaxWorkingSetSize de Metal, et Localia télécharge du Q4_K_M. Taille et vitesse sont recalculées pour les deux.llmfit 以總記憶體與它偏好的量化方式推算。但 GPU 只能使用 Metal 的 recommendedMaxWorkingSetSize，而 Localia 下載的是 Q4_K_M。因此大小與速度都會依這兩點重新計算。

  • Why measurePourquoi mesurer為何要量測

    Estimates were about twice off on an M5. On first load, Localia records the real tokens per second and memory, and recalibrates.Les estimations étaient fausses d'environ 2× sur un M5. Au premier chargement, Localia relève les vrais tokens par seconde et la mémoire, puis recalibre.在 M5 上，估計值偏差約兩倍。首次載入時，Localia 會記錄實際的每秒 token 數與記憶體用量，並重新校準。

  • Why speed firstPourquoi la vitesse d'abord為何速度優先

    A model you wait for is a model you stop using. Below about 15 tokens per second a model is flagged slow, and community fine-tunes ("uncensored", "distilled"…) are left out.Un modèle qu'on attend est un modèle qu'on abandonne. Sous 15 tokens par seconde environ, un modèle est signalé lent, et les fine-tunes communautaires (« uncensored », « distilled »…) sont écartés.需要等待的模型，終究會被放棄。每秒低於約 15 個 token 的模型會被標示為慢，社群微調版本（「uncensored」、「distilled」等）也會被排除。

What "fits" meansCe que « tenir » veut dire「放得下」是什麼意思

On Apple Silicon the GPU shares the RAM, but not all of it.Sur Apple Silicon, le GPU partage la RAM, mais pas toute.在 Apple Silicon 上，GPU 與系統共用記憶體，但不是全部。

The model has to sit inside the GPU's working set, with room left for the context. If it does not, the Mac swaps and generation slows to a crawl. That is the failure Localia is built to avoid, and why it warns before loading when memory is short.Le modèle doit tenir dans le working set du GPU, avec de la place pour le contexte. Sinon, le Mac swappe et la génération s'effondre. C'est l'échec que Localia est conçu pour éviter, et la raison pour laquelle il prévient avant de charger quand la mémoire manque.模型必須放進 GPU 的工作集，並為上下文留出空間。否則 Mac 會開始使用置換空間，生成速度將急遽下降。這正是 Localia 要避免的情況，也是它在記憶體不足時會於載入前提醒的原因。

Local mode, wire by wireLe mode local, fil à fil本機模式，逐條拆解

Like airplane mode: one switch sends Claude Code to the local model.Comme le mode avion : un interrupteur envoie Claude Code vers le modèle local.就像飛航模式：一個開關，就讓 Claude Code 改用本機模型。

  • Localia's sessions onlySessions de Localia uniquement僅限 Localia 的工作階段

    The default. Sessions launched from the menu bar get an isolated config, so your own ~/.claude is never touched and no Anthropic account is needed.Le réglage par défaut. Les sessions lancées depuis la barre de menus reçoivent une configuration isolée : votre ~/.claude n'est jamais modifié et aucun compte Anthropic n'est nécessaire.預設值。從選單列啟動的工作階段使用獨立設定，因此絕不會動到你自己的 ~/.claude，也不需要 Anthropic 帳號。

  • Every claude you typeChaque claude que vous tapez你輸入的每個 claude

    Opt-in. A marked block in ~/.zshrc loads a small shim, so claude in any terminal follows the switch. While local mode is on, it never falls back silently to the cloud.Sur option. Un bloc balisé dans ~/.zshrc charge un petit shim : claude, dans n'importe quel terminal, suit l'interrupteur. Tant que le mode local est activé, il ne se rabat jamais en silence sur le cloud.選用。~/.zshrc 中一段有標記的區塊會載入一個小型 shim，讓任何終端機裡的 claude 都跟隨開關。本機模式開啟時，絕不會悄悄改用雲端。

This is the whole block Localia adds to ~/.zshrc. A backup of the file is taken first, and the "Remove Localia from my shell" button, in Settings, deletes exactly these three lines.Voici tout le bloc que Localia ajoute à ~/.zshrc. Une sauvegarde du fichier est faite avant, et le bouton « Retirer Localia de mon shell », dans les Réglages, supprime exactement ces trois lignes.這就是 Localia 加入 ~/.zshrc 的完整區塊。寫入前會先備份該檔案，而「設定」中的「Remove Localia from my shell」按鈕只會刪除這三行。

# >>> localia >>>
[ -f "$HOME/Library/Application Support/Localia/shell/claude.zsh" ] && source "$HOME/Library/Application Support/Localia/shell/claude.zsh"
# <<< localia <<<

Local, and why not only localLe local, et pourquoi pas seulement本機，但不只本機

A complement to the cloud, not a replacement.Un complément au cloud, pas un remplaçant.是雲端的補充，而非取代。

  • SovereigntySouveraineté資料自主

    In local mode, prompts and code never leave the Mac. Useful for sensitive code.En mode local, prompts et code ne quittent jamais le Mac. Utile pour le code sensible.本機模式下，提示與程式碼從不離開 Mac。適合處理敏感程式碼。

  • Cost and reachCoût et portée成本與可用性

    Inference on a Mac you already own costs no tokens and no per-seat API fees, and works offline: on a plane, on a train, on a restricted network.L'inférence sur un Mac que vous possédez déjà ne coûte aucun token ni frais d'API par poste, et fonctionne hors ligne : en avion, en train, sur un réseau restreint.在你已擁有的 Mac 上推論，不花 token，也沒有按席位計費的 API 費用，且可離線使用：飛機上、火車上、受限網路中皆可。

  • The honest limitLa limite, honnêtement坦白說的限制

    Local models are smaller than frontier cloud models. Use them for quick tasks, offline work and cost control; switch local mode off for the hard problems.Les modèles locaux sont plus petits que les modèles de pointe du cloud. Utilisez-les pour les tâches rapides, le travail hors ligne et la maîtrise des coûts ; coupez le mode local pour les problèmes difficiles.本機模型比雲端的前沿模型小。適合快速任務、離線工作與控制成本；遇到困難問題時，關閉本機模式即可。

Next on the roadmap: an MLX engine with an Anthropic-API gateway, then other coding tools: Codex, OpenCode, Pi.Prochaines étapes : un moteur MLX avec une passerelle compatible avec l'API d'Anthropic, puis d'autres outils de code : Codex, OpenCode, Pi.後續規劃：MLX 引擎與相容 Anthropic API 的閘道，接著支援其他程式開發工具：Codex、OpenCode、Pi。
